# CodeGraph v1.6.0-personal.12

本次个人预发布合入上游 v1.6.1，并集中增强索引新鲜度说明、Explore 检索质量、关系证据和 LSP 语义能力。

### Highlights

- 合入上游 v1.6.1 的索引、解析、同步、daemon、查询池和 viewer 门禁改进；个人 schema 迁移提升到 13，提取版本提升到 28，并为个人旧库补充上游 synthesis 迁移桥接。
- `status` 和普通查询会区分活动 watcher、其他进程持有 writer lock、环境关闭监听、WSL 限制与启动失败；stale 源码提示给出与实际监听状态一致的恢复动作。
- `codegraph_explore` 为清单、比较、能力和存在性问句前置有界答案；启动入口识别支持 package `main`、HTML 脚本和 Spring Boot，公共目录词不再压过真实功能名。
- 关系输出统一标注 `resolved`、`inferred`、`candidate`，显示关系两端定义位置与调用/注册位置；精确目标展示明细，宽问句保留紧凑摘要和源码预算。
- LSP 查询新增 hover、类型定义、实现、调用层级、类型层级、全项目诊断和 Code Action；自动修复默认预览，拒绝命令执行、文件创建/移动/删除和项目外写入，应用仍走事务与哈希校验。
- 原生内核补齐引用坐标和动态 namespace import，与 WASM 路径保持一致；同时修复 macOS 安装来源比较和真实 LSP CI 环境准备。

### Installation

推荐 Node.js 24（最低 Node.js 20）：

```powershell
npm install -g "https://github.com/nk33-dev/codegraph/releases/download/v1.6.0-personal.12/colbymchenry-codegraph-1.6.0-personal.12.tgz"
codegraph doctor --json
codegraph sync --upgrade-index --yes
```

安装后完整退出并重新打开 MCP 客户端。旧索引会升级 schema；从提取版本 27 升到 28 时，当前登记范围要求完整重抽取。

### Verification boundary

- Windows、Node 24：类型检查通过；四个 worktree 与交叉冲突面的 15 个定向测试文件共 202 项通过、1 项按既有条件跳过。
- Explore 关系明细的合并回归通过预算、跨调用去重和 blast radius 专项测试，共 54 项通过。
- 发布准备 `npm run check:quick` 通过：252 项通过、13 项按既有平台条件跳过；版本镜像检查通过。
- 完整构建、全量测试、隔离安装、打包、校验和、标签和 prerelease 由 GitHub CI 与 `Personal Release` 执行；发布前必须等待同一提交的三平台 CI 成功。

### Known limitations

- 动态字符串、运行时注册、宏生成及嵌入脚本的调用关系仍取决于可静态确认的证据。
- Code Action 不执行语言服务器返回的命令，也不应用文件创建、重命名或删除；这些动作应在 IDE 中完成。
- 真实语言服务器、原生内核和长时间 daemon 恢复场景由 Hardening 工作流验证，不把假服务器回归测试等同于真实依赖验证。
