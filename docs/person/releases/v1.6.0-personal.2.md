# CodeGraph v1.6.0-personal.2

> 发布后确认：三平台运行 `35131681211` 仍有 macOS 路径/事务测试和 Linux/macOS LSP fixture 隔离失败。本版本不能视为三平台验证通过；修复先进入 `personal`，不移动本标签。

这是个人版的第二个预发布修订，包含 `v1.6.0-personal.1` 的全部查询、编辑、LSP、资源治理和安装能力，并修复首次三平台 CI 实跑发现的跨平台问题。该版本只通过 GitHub Release 交付 `.tgz`，不发布到 npm registry，也不运行上游发行流程。

### Highlights

- `codegraph_explore` 统一提供源码、调用路径、证据、实现者、动态分派、改动影响和关联测试。
- Graph 与 LSP 共用版本化查询契约，支持自动路由、双源合并以及明确的来源和降级说明。
- `codegraph_edit` 默认预览，支持跨文件重命名、正文替换、前后插入、幂等 operation ID、失败回滚和中断恢复。
- 多窗口可共享 daemon、查询 worker 和语言服务器，并按资源档位限制和回收空闲资源。
- 安装包包含 CLI、viewer、SQL 与 29 个 grammar WASM，并执行隔离安装验证。

### New Features

- 支持 definitions、references、symbols、status、impact 和 tests 等结构化查询模式，CLI、MCP 与公共库复用同一实现。
- 支持 C、C++、JavaScript、TypeScript、Java、Rust、Go 和 Python 的按需语言服务查询，以及真实 LSP 跨文件重命名。
- 支持 Git 改动符号、语义边差异、影响入口、关联测试和显式深度基准图分析。
- 提供统一证据与置信度、接口实现者展开，以及 Zustand 等高价值动态分派补全。
- 提供 `battery`、`balanced`、`performance` 资源档位、查询池自动缩容、LSP 空闲退出和跨 daemon 租约。
- `codegraph doctor` 显示个人发行标记、实际入口和构建来源；个人版禁用官方升级和上游发布目标。

### Fixes

- Windows worktree 检测按真实目录身份比较路径，兼容 Git 长路径与 Node 8.3 短路径的不同拼写。
- macOS 安装器契约统一使用 canonical 临时目录，不再混淆 `/var` 与 `/private/var`。
- 跨卷拒绝和多文件回滚使用确定性的事务测试钩子，不再依赖不同平台的模块绑定行为。
- URI 测试按平台文件系统语义断言大小写，Python LSP 复用按实际服务进程验证。
- CFML 接收者推导集成测试增加合理超时，并在失败路径释放数据库资源。
- 个人 CI、Hardening 和发布工作流升级到 `actions/checkout@v6` 与 `actions/setup-node@v6`。

### Installation

需要 Node.js 20 至 24，推荐 Node.js 24：

```powershell
npm install -g "https://github.com/nk33-dev/codegraph/releases/download/v1.6.0-personal.2/colbymchenry-codegraph-1.6.0-personal.2.tgz"
codegraph doctor --json
```

也可以从固定标签重新打包安装：

```powershell
npm pack "github:nk33-dev/codegraph#v1.6.0-personal.2"
npm install -g ".\colbymchenry-codegraph-1.6.0-personal.2.tgz"
```

升级后建议对已有项目重新执行 `codegraph index`，再重新连接 MCP 客户端。

### Known Limitations

- 该 `.tgz` 是源码构建包，不包含上游正式发行版的捆绑 Node 或原生 Rust kernel；解析使用 WASM 路径。
- 语言服务器需要用户单独安装，CodeGraph 不会自动下载。
- 真实小、中、大仓库 Agent A/B、能耗测量以及三平台 Hardening 仍待后续执行。
- 完整开发依赖审计仍有 Vitest 2/Vite 5 工具链告警；它们不进入发布运行时，升级需要独立验证。
