# CodeGraph v1.6.2-personal.2

**状态：已发布（2026-10-06）。** 标签 `v1.6.2-personal.2` 指向提交 `470002c2d301c07d940172c6957599a7681a44b3`，三平台 CI、隔离安装、资产校验和 GitHub prerelease 均已完成。

本版把官方 v1.6.2 之后的最新解析器和 daemon 修复接入个人 fork，并保留个人查询、LSP、结构化编辑、资源治理和遥测契约。

### Highlights

- **多语言关系更完整。** C#/VB.NET 属性和初始化、Dart 注解/库可见性/调用链/import prefix、Go 多模块、Rust 枚举变体以及 JavaScript/TypeScript 对象字面量的调用关系得到官方修复。
- **Vue 与 COBOL 检索更准确。** Vue 模板调用和 COBOL copybook 的源文件、包含位置会进入结构化查询结果。
- **daemon 会识别安装变化。** 安装被替换或移除时，旧 daemon 会退出，客户端可启动当前安装的版本；版本切换继续校验进程身份和个人构建指纹。
- **索引健康状态更明确。** 文件缺少符号或存在解析错误时，状态会列出文件并建议同步；升级计划通过 v29 条件桥接补齐官方 C#/VB.NET 提取变化，当前提取版本为 30。

### Installation

推荐 Node.js 24；从源码运行需要 Node.js 22.5 及以上。

```powershell
npm install -g "https://github.com/nk33-dev/codegraph/releases/download/v1.6.2-personal.2/colbymchenry-codegraph-1.6.2-personal.2.tgz"
codegraph doctor --json
codegraph install --refresh
```

安装后完整退出并重新打开 MCP 客户端；已有索引建议运行 `codegraph sync --upgrade-index`。

### Known limitations

- 提取版本升级需要重新提取受影响索引；旧库不会通过 schema 迁移自动获得新增关系。
- 动态注册、反射和运行时计算路径仍可能缺少静态关系，结构化结果会保留边界说明。
