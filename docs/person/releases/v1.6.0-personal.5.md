# CodeGraph v1.6.0-personal.5

本次个人预发布包含 personal.4 发布后的 CI、资源清理修复，以及重命名补全、检索意图收束和升级体验改进。

### Highlights

- 跨文件重命名可补齐索引中位置已确认、语言服务器遗漏的引用，并在预览标注编辑来源；无法核实的缺口仍拒绝应用。
- “定义、所有调用方和相关测试”等自然语言意图不再挤占唯一精确符号的检索结果。
- 新增 `codegraph sync --upgrade-index`，先展示索引升级范围、预计耗时和磁盘占用；非交互执行需加 `--yes`。
- 升级后发现版本不匹配的共享服务时尝试自动切换，也可用 `codegraph daemon --restart` 手动重启。
- 修复索引失败连接泄漏、数据库后台线程提前返回和测试超时清理，Windows CI 恢复四并发。
- 修复 personal.4 的 UI 版本同步、精确检索预算回退和升级提示契约问题。

### Installation

推荐 Node.js 24（包内不捆绑 Node，SQLite 运行时需要 Node.js 22.5 或更新的受支持版本）：

```powershell
npm install -g "https://github.com/nk33-dev/codegraph/releases/download/v1.6.0-personal.5/colbymchenry-codegraph-1.6.0-personal.5.tgz"
codegraph doctor --json
```

安装后完整退出并重新打开 Codex 等 MCP 客户端。若索引提示需要升级，执行 `codegraph sync --upgrade-index`。

### Known limitations

- 动态导入与未索引引用仍有覆盖边界，重命名覆盖检查不等于完整性证明。
- 历史提取升级未登记语言范围，目前旧索引升级保守执行完整重建；耗时和磁盘数字为估算。
- daemon 版本切换未在真实 MCP 客户端中完成升级演练；本地全量负载下的接管偶发项仍需跟踪。
- 本版为 GitHub 个人预发布，不发布 npm registry；包内不含上游原生 Rust kernel 或语言服务器。
