# CodeGraph v1.6.0-personal.3

该个人预发布版重新打包完整的结构化查询、安全编辑、语言服务和资源治理能力，并纳入 `v1.6.0-personal.2` 发布后发现的跨平台修复。行为基线已通过 Windows、Ubuntu 和 macOS CI。

### Highlights

- `codegraph_explore` 在一次响应中组合源码、调用路径、证据、实现者、动态分派、改动影响和关联测试。
- Graph 与 LSP 共用查询契约，支持自动路由、双源合并，并明确显示实际来源和降级原因。
- `codegraph_edit` 默认预览，支持跨文件重命名、正文替换、前后插入、幂等 operation ID、失败回滚和中断恢复。
- 多窗口共享 daemon、查询 worker 和语言服务器，并按资源档位回收空闲资源。
- GitHub Release 安装包包含 CLI、viewer、SQL 和 29 个 grammar WASM，不依赖 npm Git 临时缓存。

### New Features

- 支持 definitions、references、symbols、status、impact 和 tests 等结构化查询模式，CLI、MCP 与公共库复用同一实现。
- 支持 C、C++、JavaScript、TypeScript、Java、Rust、Go 和 Python 的按需语言服务查询与真实跨文件重命名。
- 支持 Git 改动符号、语义边差异、影响入口、关联测试和显式深度基准图分析。
- 提供统一证据与置信度、接口实现者展开，以及 Zustand 等高价值动态分派补全。
- 提供 `battery`、`balanced`、`performance` 资源档位、查询池自动缩容、LSP 空闲退出和跨 daemon 租约。
- 新增快速分层验证命令，日常修改可运行 `npm run check:quick` 或指定测试，不必重复完整构建和全量测试。

### Fixes

- Windows worktree 检测按真实目录身份比较，兼容 Git 长路径和 Node 8.3 短路径的不同拼写。
- macOS 安装器契约正确处理 `/var` 与 `/private/var` 指向同一临时目录的情况。
- 跨卷拒绝和多文件回滚使用确定性的事务注入，不再依赖平台模块绑定或路径拼写。
- Python LSP 复用测试只配置 Python 服务，并逐次确认查询和编辑复用同一个服务进程。
- Windows 并发索引集成测试使用统一超时上限，失败路径会先关闭 SQLite，避免 `EBUSY` 连锁失败。
- 个人 CI 使用 Node 24 action 运行时，并避免 tag 和纯文档变更重复触发三平台任务。

### Installation

需要 Node.js 20 至 24，推荐 Node.js 24：

```powershell
npm uninstall -g @colbymchenry/codegraph
npm install -g "https://github.com/nk33-dev/codegraph/releases/download/v1.6.0-personal.3/colbymchenry-codegraph-1.6.0-personal.3.tgz"
codegraph doctor --json
```

升级后建议对已有项目重新执行 `codegraph index`，再重新连接 MCP 客户端。不要执行 `codegraph uninit`，它会删除项目索引。

### Known Limitations

- 该 `.tgz` 是源码构建包，不包含上游正式发行版的捆绑 Node 或原生 Rust kernel；解析使用 WASM 路径。
- 语言服务器需要用户单独安装，CodeGraph 不会自动下载。
- 真实小、中、大仓库 Agent A/B、能耗测量以及三平台 Hardening 仍待后续执行。
- 完整开发依赖审计仍有 Vitest 2/Vite 5 工具链告警；它们不进入发布运行时，升级需要独立验证。
