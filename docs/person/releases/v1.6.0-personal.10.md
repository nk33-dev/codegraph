# CodeGraph v1.6.0-personal.10

本次个人预发布改进自然语言检索、文件内容搜索与大型项目的查询控制。

### Highlights

- “项目如何启动”一类问句可定位常见入口并沿调用图展开；模块名、带扩展名的文件名和路径可指向同一索引文件。
- 未找到代码时给出相近符号、文件或更具体查询的建议，而不是只返回空结果。
- `mode: "text"` 搜索源码之外的配置、文档及脚本内容，按文件分页；旧索引升级后需运行 `codegraph sync` 建立文本索引。
- `mode: "callers"` / `"callees"` 单独分页展示调用关系与证据来源；`mode: "source"` 按行范围读取源码，避免整篇大文件挤占输出。
- 状态显示索引提交与当前提交、文本索引落后文件；变更文件不返回过时的文本片段。
- Windows 测试进程清理等待实际进程退出，避免共享标准流拖延临时目录清理。

### Installation

推荐 Node.js 24（SQLite 运行时需要 Node.js 22.5 或更新的受支持版本）：

```powershell
npm install -g "https://github.com/nk33-dev/codegraph/releases/download/v1.6.0-personal.10/colbymchenry-codegraph-1.6.0-personal.10.tgz"
codegraph doctor --json
codegraph sync
```

安装后完整退出并重新打开 MCP 客户端。

### Known limitations

- 动态字符串、运行时注册、宏生成及嵌入脚本的调用关系仍取决于可静态确认的证据；推断关系标出置信度，不能保证覆盖全部运行时路径。
- 文本查询仅索引可读取的受支持文件；敏感配置值、二进制及过大文件不会作为搜索结果泄露。
