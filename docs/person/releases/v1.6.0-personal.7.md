# CodeGraph v1.6.0-personal.7

本次个人预发布修复精确自然语言检索、旧索引下的重命名安全性和大型编辑预览的上下文开销。

### Highlights

- “定义、所有直接调用方和相关测试”现在按结构化意图执行并分类输出，可稳定包含动态 namespace import 的真实调用方，不再混入同名前缀函数。
- 自然语言 explore、结构化 references 和重命名覆盖检查复用同一套 Graph 入边推导；已有语言服务器时还会合并 LSP 引用来源。
- 提取版本过旧且重命名依赖跨文件 Graph 覆盖时返回 `canApply:false`，即使请求 `apply:true` 也会在写盘前拒绝，并提示运行 `codegraph sync --upgrade-index`。
- MCP 和 CLI 的编辑文本默认按文件汇总，每文件最多展示三个代表编辑；完整位置、哈希和预览仍保留在 `structuredContent`。
- 需要完整人工审计时可传 `verbosePreview:true`，或在 CLI 使用 `--verbose`；展示模式不会改变 preview hash 或 operation ID。

### Installation

推荐 Node.js 24（包内不捆绑 Node，SQLite 运行时需要 Node.js 22.5 或更新的受支持版本）：

```powershell
npm install -g "https://github.com/nk33-dev/codegraph/releases/download/v1.6.0-personal.7/colbymchenry-codegraph-1.6.0-personal.7.tgz"
codegraph doctor --json
```

安装后完整退出并重新打开 Codex 等 MCP 客户端。若状态提示索引提取版本过旧，先执行：

```powershell
codegraph sync --upgrade-index --yes .
```

### Known limitations

- Graph 与 LSP 都无法证明未索引、反射、运行时计算键或无法解析别名的引用；这类重命名仍应拒绝或人工复核。
- 自然语言 explore 默认不会冷启动语言服务器；已有对应 LSP 进程时自动合并，显式 `backend:"both"` 可要求启动并合并。
- 本版只通过 GitHub 个人预发布交付，不发布 npm registry；包内不含上游原生 Rust kernel 或语言服务器。
