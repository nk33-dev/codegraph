### Highlights

- JSON 键能找到多语言字段声明、别名、声明类型和序列化方向。
- Tauri 泛型 invoke、注册命令和静态桥接路径进入调用关系，保留注册证据与候选边界。
- 分片与产物的重复定义折叠，生成脚本、manifest、include_str 消费位置可查；漂移保留产物坐标。
- 文档提及可用 `documents` 反查，改动上下文附带相关文档；中文未命中时返回有预算的本地文本候选。
- 合入官方 32 个提交，修复 Go/C++/Dart、框架绑定、增量引用重试和大型 JS bundle；保留个人迁移与接收者坐标约定。

已有索引需要运行 `codegraph sync --upgrade-index --yes`，以提取版本 31 获取新增关系。数据库 schema 为 18，打开可写连接时自动迁移。

### Installation

```powershell
npm install -g "https://github.com/nk33-dev/codegraph/releases/download/v1.6.2-personal.3/colbymchenry-codegraph-1.6.2-personal.3.tgz"
codegraph doctor --json
codegraph install --refresh
```

安装后重新打开 MCP 客户端，运行索引升级。
