# CodeGraph v1.6.0-personal.1

首个个人预发布版集中交付结构化代码查询、安全编辑、语言服务集成和多窗口资源治理。该版本从 GitHub Release 安装，不发布到 npm registry，也不会覆盖上游发布流程。

### Highlights

- `codegraph_explore` 可以在一次回答中组合源码、调用路径、证据、实现者、动态断点、改动影响和关联测试。
- Graph 与 LSP 使用统一查询契约，支持自动路由、双源合并，并明确说明实际使用的来源与降级原因。
- `codegraph_edit` 默认只预览，跨文件应用具备幂等 operation ID、事务提交、失败回滚和中断恢复。
- 多窗口和子 Agent 共享 daemon、查询 worker 与语言服务器，并通过资源档位限制和回收空闲资源。
- 安装包包含 CLI、viewer、SQL 与 29 个 grammar WASM，并通过隔离安装验证。

### New Features

- 增加 definitions、references、symbols、status、impact 和 tests 等结构化查询模式，CLI、MCP 与公共库复用同一实现。
- 增加 C、C++、JavaScript、TypeScript、Java、Rust、Go 和 Python 的按需语言服务查询；Python 与 TypeScript 已覆盖真实服务集成路径。
- 增加符号重命名、正文替换、前后插入，以及 `previewHash`、陈旧文件拒绝和写后索引刷新。
- 增加 Git 改动符号、语义边差异、影响入口、关联测试与显式深度基准图分析。
- 增加统一证据与置信度、接口和抽象方法实现者展开，以及 Zustand 等高价值动态分派补全。
- 增加 `battery`、`balanced`、`performance` 资源档位、查询池自动缩容、LSP 空闲退出和跨 daemon 全局租约。
- CLI 可以复用现有 daemon 的查询与语言服务器；daemon 不可用时只读操作诚实回退，未确认的写操作不会本地重放。
- `codegraph doctor` 显示实际运行入口、个人发行标记和构建 ID；个人版禁用官方更新提示和上游发布目标。

### Fixes

- 结构性编辑遇到索引写锁竞争时不再误报索引已刷新，而是提示稍后执行 `codegraph sync`。
- 关闭一个项目的语言服务管理器时，不再删除同一 daemon 中其他项目的活动租约。
- 活跃 LSP 请求不会被空闲回收中断，输入管道关闭也不会因异步 EPIPE 中断宿主进程。
- Windows 测试子进程统一隐藏窗口并使用稳定的 WASM 运行参数，降低 Node 24 高并发崩溃。
- 修复多项查询分页、路径边界、旧 Git、工作树切换和增量索引收敛问题。
- 更新 Rollup、PostCSS 和 NanoID 到兼容范围内的安全版本；发布运行时依赖审计为 0 个已知漏洞。

### Installation

需要 Node.js 20 至 24，推荐 Node.js 24：

```powershell
npm install -g "https://github.com/nk33-dev/codegraph/releases/download/v1.6.0-personal.1/colbymchenry-codegraph-1.6.0-personal.1.tgz"
codegraph doctor --json
```

也可以从固定标签重新打包安装：

```powershell
npm pack "github:nk33-dev/codegraph#v1.6.0-personal.1"
npm install -g ".\colbymchenry-codegraph-1.6.0-personal.1.tgz"
```

升级后建议对已有项目重新执行 `codegraph index`，再重新连接 MCP 客户端。

### Known Limitations

- 该 `.tgz` 是源码构建包，不包含上游正式发行版的捆绑 Node 或原生 Rust kernel；解析会使用现有 WASM 路径。
- 语言服务器需要用户单独安装，CodeGraph 不会自动下载。
- 真实小、中、大仓库 Agent A/B、能耗测量以及三平台 Hardening 仍待后续执行。
- 完整开发依赖审计仍有 Vitest 2/Vite 5 工具链告警；它们不进入发布运行时，升级需要独立验证。
