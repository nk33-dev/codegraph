# CodeGraph v1.6.0-personal.11

本次个人预发布修复 Claude Code 使用 MCP 时的源码可见性、查询排序、索引覆盖和 Hook 噪声问题，并降低大型项目影响分析的额外开销。

### Highlights

- Claude Code 的 `codegraph_explore` MCP 响应统一保留完整源码文本，避免客户端只展示结构化摘要。
- 大文件文本搜索会明确报告覆盖范围，并在有界预算内补扫超大文本文件；标识符内部的字符串也可以搜索。
- 定义、影响分析和关联测试结果按生产代码、测试、距离和置信度排序，文件名推测的测试单独标记为低置信度。
- diagnostics 查询默认选择可用的语言服务器，文件路径可以直接写在查询中；语言服务器仍在索引时会明确提示结果可能不完整。
- 普通聊天、图片和文档附件不会触发 Claude Code 前置 Hook；只有索引中确认的代码标识符或源码路径才会注入上下文。
- 改动上下文会忽略纯行号偏移和换行符变化；影响分析和测试分类减少重复扫描。
- 错误、诊断、MCP/API 和 Agent 提示统一使用英文，真人交互式 CLI 文案继续使用中文。

### Installation

推荐 Node.js 24（SQLite 运行时需要 Node.js 22.5 或更新的受支持版本）：

```powershell
npm install -g "https://github.com/nk33-dev/codegraph/releases/download/v1.6.0-personal.11/colbymchenry-codegraph-1.6.0-personal.11.tgz"
codegraph doctor --json
codegraph sync
```

安装后完整退出并重新打开 MCP 客户端。

### Verification boundary

- Windows、Node 24：类型检查、定向回归、源码 CLI Hook、全文索引升级与补扫测试通过。
- 完整构建、全量测试、隔离安装、打包和校验和由 GitHub `Personal Release` 执行；发布前必须等待同一提交的三平台 CI 成功。
- 真实仓库检索 A/B、跨平台 CI 和真实 Claude Code 宿主展示仍以 GitHub 工作流及实际客户端结果为准。

### Known limitations

- 动态字符串、运行时注册、宏生成及嵌入脚本的调用关系仍取决于可静态确认的证据。
- 不相关文件召回策略保留现状，等待真实仓库 A/B 评估后再调整。
