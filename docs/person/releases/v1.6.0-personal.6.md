# CodeGraph v1.6.0-personal.6

本次个人预发布集中交付 MCP 固定上下文、状态输出稳定性和 personal.5 发布后的正确性修复。

### Highlights

- 默认 MCP 仍只暴露 `codegraph_explore` 与 `codegraph_edit`，固定表面从 20,338 个字符收敛到 7,024 个字符；工具定义不再随仓库规模变化。
- `codegraph_explore` 的结构化模式保持统一入口，`maxFiles` 不再声明与运行时分档冲突的固定默认值，显式工具白名单也不会被小仓库规则覆盖。
- stale banner、footer 和 status 使用稳定状态并按路径排序；结构化 status 保留原有时间字段，避免破坏既有消费方。
- 首次 MCP 调用可分别观察 catch-up 等待与实际检索耗时；成功、超时和失败分别计量，不改变原有正确性门和超时降级行为。
- 匿名遥测改为默认关闭，未显式开启时不记录、不落盘也不联网。
- 编辑后的索引刷新补齐 grammar 预加载与引用解析，动态 namespace import 和精确调用位置可参与已验证的重命名补全。

### Installation

推荐 Node.js 24（包内不捆绑 Node，SQLite 运行时需要 Node.js 22.5 或更新的受支持版本）：

```powershell
npm install -g "https://github.com/nk33-dev/codegraph/releases/download/v1.6.0-personal.6/colbymchenry-codegraph-1.6.0-personal.6.tgz"
codegraph doctor --json
```

安装后完整退出并重新打开 Codex 等 MCP 客户端。运行中的旧 MCP 会话不会自动加载新工具定义。

### Verification boundary

- 本机 Windows、Node 24.16.0：最终类型检查通过；受影响测试 877 项通过、3 项按环境跳过。唯一初次失败来自 CLI 用例读取旧 `dist`，重新构建后该文件 10/10 通过。
- `npm run build` 已通过，包含 TypeScript、viewer、SQL/WASM 与构建指纹；个人 Release 工作流还会执行隔离 tarball 安装验证。
- `npm run verify:personal-install` 已通过：隔离安装后的 doctor、UI 资源、29 个 grammar WASM、Python 图查询、事务 apply 与幂等重放均正常。
- 发布提交推送后，以 Windows、Ubuntu、macOS CI 和 Personal Release 工作流的实际结果为准，不沿用旧标签的 CI 结论。
- 未执行真实宿主 Agent A/B；本版没有加入未经验证的查询预算或关系裁剪开关，也不声称模型 token、Read/Grep 或墙钟收益。

### Known limitations

- `CODEGRAPH_EXPLORE_DEDUP` 仍默认关闭；只有宿主能保证一条 MCP 连接对应持续存在的模型上下文时才适合开启。
- catch-up 超时后仍按既有行为先返回结果并在后台完成对账；停机期间删除文件尚无等价的新鲜度快路径。
- Graph 覆盖检查不能证明未索引、运行时或别名引用全部完整；无法核实的重命名缺口仍拒绝应用。
- 本版只通过 GitHub 个人预发布交付，不发布 npm registry；包内不含上游原生 Rust kernel 或语言服务器。
