# CodeGraph v1.6.0-personal.8

本次个人预发布修复 explore 的两处输出不一致，并让 MCP 固定表面预算重新跟上工具 schema 的真实开销。

### Highlights

- blast radius 行首的数量与它列出的文件现在同源：测试节点只计为测试文件，不再混进生产调用方。用户报告过的“2 callers in `src/bin/codegraph.ts`”（实际是 `main` 一个直接调用方，另一个是测试文件）现在输出为 ``1 production dependent + 1 test file: 1 caller in `src/bin/codegraph.ts`; tests: `upgrade.test.ts` ``。
- 同一个文件经模块 `imports` 边和文件内具体调用符号各计一次的问题一并修掉：有具体符号时只保留具体符号，纯导入文件仍单独归为 importer。
- 自然语言要求“相关测试”时，测试文件默认输出**测试摘要**而不是整篇测试源码：列出测试声明及其行号，每个声明用 `// exercises …` 标注它实际调用的生产符号，长测试体只抽样并注明省略。用户报告的一次 23,508 字符 / 587 行响应里，测试源码是主要来源。
- 测试全文仍可取回：`codegraph_explore` 传 `includeTestSource: true` 按普通源码渲染该文件，或再次 explore 该测试名（测试文件是普通索引文件，`mode: tests` 等结构化模式不受影响）。未请求测试的查询行为完全不变，80 行以下的测试文件也不摘要。
- 修正上一版引入的固定表面超限：`includeTestSource` 描述压到最短，explore schema 净增 173 字符；字符预算测试的上限改为共用一组常量（此前同一个量在两个用例里各写一个数字，一次改动只会撞破其中一个）。

### Installation

推荐 Node.js 24（包内不捆绑 Node，SQLite 运行时需要 Node.js 22.5 或更新的受支持版本）：

```powershell
npm install -g "https://github.com/nk33-dev/codegraph/releases/download/v1.6.0-personal.8/colbymchenry-codegraph-1.6.0-personal.8.tgz"
codegraph doctor --json
```

安装后完整退出并重新打开 Codex 等 MCP 客户端。

### Known limitations

- 测试摘要按“测试声明 + 其调用边指向的生产符号”生成：调用边缺失（反射、动态分派、未解析别名）时，该声明可能只显示声明本身而不列出被调用的符号。
- 测试文件大于 80 行才启用摘要；更小的测试文件按普通源码渲染，因为摘要省不了多少字节。
- 本版只通过 GitHub 个人预发布交付，不发布 npm registry；包内不含上游原生 Rust kernel 或语言服务器。
