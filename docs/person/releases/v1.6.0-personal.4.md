# CodeGraph v1.6.0-personal.4

本次个人预发布汇总跨文件编辑安全、检索结果和安装升级修复。不包含后续计划中的 MCP/CLI 模块重构与动态导入覆盖扩展。

### Highlights

- 重命名预览会报告 Graph 已知引用与 LSP 编辑的覆盖缺口，存在已确认缺口时拒绝应用；按位置发起的重命名同样受检查。
- 事务提交前复核内容，失败回滚保留外部编辑器的新修改，并提供恢复清单。
- 精确单符号查询优先展示定义、直接调用和请求的测试；局部查询不再夹带整个工作区变更。
- 关联测试区分直接、高置信度与间接候选，默认隐藏宽依赖链上的候选，可显式展开。
- 个人版新增 GitHub Release 一键升级，并核对安装身份与实际 PATH 入口。

### Fixes

- 修复间接测试展开参数在统一路由中丢失，以及分类结果受遍历顺序影响的问题。
- 修复同一行引用覆盖误判、陈旧引用位置和按位置重命名绕过覆盖检查的问题；无法核实的别名或动态关系仍明确提示。
- 修复事务锁异常导致整笔操作重试、空锁被过早抢占和回滚误删其他程序创建目标的风险。
- 索引提取版本过期时，`codegraph sync` 明确提示完整重建；写锁繁忙时返回非零退出码。
- 安装与配置刷新即使没有修改配置字节，也会提示完整重启相关 MCP 客户端。

### Installation

需要 Node.js 20 至 24，推荐 Node.js 24：

```powershell
npm install -g "https://github.com/nk33-dev/codegraph/releases/download/v1.6.0-personal.4/colbymchenry-codegraph-1.6.0-personal.4.tgz"
codegraph doctor --json
```

旧版 personal.3 的 upgrade 仍只显示安装方法，首次切换请使用上述命令。安装后完整退出并重新打开 Codex 等 MCP 客户端。若 status 提示 `reindexRecommended`，在对应项目目录执行 `codegraph index -f .`。

### Verification boundary

- 开发复审只检查源码、调用链与差异；按用户要求未运行本地测试、类型检查或隔离安装测试。
- 发行阶段从本批提交生成 CLI、viewer、SQL/WASM 和构建指纹，再打包 `.tgz` 与 `SHA256SUMS`；不复用旧版 dist。
- 历史三平台 CI 的通过结果不代表本版通过；本次推送触发的 CI 状态以该发行提交的 Actions 结果为准。
- 本版为个人预发布，不发布 npm registry，不修改用户现有全局安装或客户端配置。

### Known limitations

- Graph 覆盖检查不能证明未索引、运行时或别名引用全部完整；动态导入覆盖扩展仍在后续计划中。
- `.tgz` 不包含捆绑 Node 或上游原生 Rust kernel，语言服务器需单独安装。
- 正式 A/B、token 与能耗报告属于可选效果评测，不作为个人项目功能完成的必要条件；资源泄漏和长期运行故障仍属于维护范围。
