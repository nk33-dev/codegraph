# CodeGraph v1.6.0-personal.9

本次个人预发布集中改进索引及时性、查询范围控制和跨层关系提示。

### Highlights

- 新增统一索引状态、生成版本和 `codegraph refresh <file>` 局部刷新。
- 新文件可以直接查看，并明确标记为未索引，不会伪造图关系。
- `codegraph_explore` 支持目录、语言、框架、符号类型、排除类型和调用深度过滤。
- Vue 动态组件和模板关系会明确标记推断证据。
- Axios/fetch 与 Spring/Express 路由可以按 HTTP 方法和路径建立候选关联；歧义结果会保留候选。
- 测试结果增加参数化、MockMvc、动态测试和前端测试证据。
- 普通索引任务使用较低并发，继续遵循 `battery`、`balanced`、`performance` 资源档位。

### Installation

推荐 Node.js 24（SQLite 运行时需要 Node.js 22.5 或更新的受支持版本）：

```powershell
npm install -g "https://github.com/nk33-dev/codegraph/releases/download/v1.6.0-personal.9/colbymchenry-codegraph-1.6.0-personal.9.tgz"
codegraph doctor --json
```

安装后完整退出并重新打开 Codex 等 MCP 客户端。

### Verification boundary

- Windows、Node 24.16.0：`npm run typecheck` 通过。
- 三个 worktree 的新增定向测试已分别通过；合并后的快速检查中，依赖 `dist/bin/codegraph.js` 的旧 CLI 测试因本地未生成构建产物而失败，交由个人发布 CI 执行构建、全量测试和隔离安装。
- 本次发布不在开发机运行完整 build、全量 test、打包或上传；`Personal Release` 负责这些步骤。

### Known limitations

- HTTP 关联是静态证据；动态 URL、代理改写和多个同路径服务只能给出候选或不连线。
- Vue 关系中的推断边不等同于运行时调用；复杂模板和动态分派仍需要 LSP 或源码确认。
