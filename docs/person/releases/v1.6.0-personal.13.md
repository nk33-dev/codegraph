# CodeGraph v1.6.0-personal.13

本版统一索引可信度、关系证据与升级报告，并修复增量同步和中断恢复中的图一致性问题。

### Highlights

- 查询先给摘要；只列主链路时折叠旁支和源码，传 `expand: true` 展开。位置查询自动选择 LSP，冷启动的暂时空结果标为 `indexing`。
- 索引分别报告提交对应状态与完整性；显示待解析数量、来源文件及调用方/影响分析可能遗漏的边界。内容标记在无变更同步后保持稳定，任务 ID 单独保留。
- 同名符号支持文件/限定名选择器和上下文排序。关系附带静态、推断、候选证据、来源和调用位置，零调用方与目标不存在分开报告。
- Vue/React 增加 composable 返回成员、路由别名、props 和 emits 关系；词法作用域拒绝同名参数和数组误连，框架内建消费引用但不画自环。
- 增量同步持久保留跨文件入边和定义差异，恢复替换/分块存储中断；节点缓存跟随其他连接的提交失效，名称词表维护回收过时记录，文本扫描让出事件循环。
- `CodeGraph.upgradeIndex()` 和 CLI 共用一次写锁，在重抽取、解析后比较关系增删、去重、类型与证据。失败保留旧提取版本，比较快照在成功和异常后清理。

### Installation

推荐 Node.js 24；从源码运行需要 Node.js 22.5 及以上（SQLite 使用 `node:sqlite`）。

```powershell
npm install -g "https://github.com/nk33-dev/codegraph/releases/download/v1.6.0-personal.13/colbymchenry-codegraph-1.6.0-personal.13.tgz"
codegraph doctor --json
codegraph sync --upgrade-index --yes
codegraph install --refresh
```

提取版本从 28 升到 29，登记全语言重抽取范围；schema 保持 13。安装后完整退出并重新打开 MCP 客户端。

### Known limitations

- 计算路由、动态组件、spread props、内联回调、反射、运行时注册与事件名仍可能缺边；推断关系不能代替编译器或运行时验证。
- Go 规模测量来自合并前的 Windows 合成样本；真实仓库总体误报率、长期多客户端负载及 Agent A/B 尚未测量。
- 真实语言服务器、原生内核和长时间 daemon 恢复由 Hardening 验证；本地假服务器回归不等于真实依赖验证。
