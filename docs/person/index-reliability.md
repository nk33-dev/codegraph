| 风险 | 本次结论与证据 |
| --- | --- |
| 边数异常增长 | 唯一约束覆盖无坐标边；Go 重复同步比较完整身份集合。跨版本长期趋势仍需相同项目、相同代码快照的持续测量，6,621→15,103 本身不能证明异常。 |
| 重复同步重复写边 | Go 连续五次无变更同步，节点、边集合保持相同。合成发布的边替换已有事务与唯一约束。 |
| 数据库持续膨胀 | 修复旧名称词表在反复改名后积累的问题，验证名称回归。测量分开记录主库、WAL、分配页、空闲页及每千文件/万行的字节数。 |
| 查询越来越慢 | 规模测量覆盖 explore、callers、impact，在无变更同步与正文编辑前后记录 p50/p95；结论限于合成样本与当前 Windows 环境。 |
| 中断恢复幂等 | 修复文件替换中断丢失跨文件入边、定义变化中断漏重解析、分块中断后再次编辑残留节点。恢复图与空库重建的完整集合一致。 |
| 推断误报 | 复现同文件两类各有 run 方法时，重挂误连另一个类；改为恢复原引用并重解析。定向回归同时覆盖同名歧义与 Go 裸调用不能指向方法。未给出真实项目的总体误报率。 |
| watcher/MCP 更新 | 修复多连接长期持有旧节点缓存与文本同步未变更分支不让出事件循环；两个只读实例验证更新与删除，事件循环用例验证同步时能服务排队任务。现有 watcher、catch-up、共享项目生命周期测试覆盖自动更新与多客户端租约。真实多客户端长时间运行仍待验证。 |

## 测量方法

`__tests__/index-reliability-benchmark.test.ts` 默认跳过，显式开启后生成临时 Go 样本（100、1,000、5,000 个文件），在公共 API 建索引，通过 MCP `ToolHandler.executeReadTool('codegraph_explore', ...)` 查询。每种模式采集 10 次新连接首次查询和 30 次热查询，再对五次正文编辑后的索引重复测量；五次无变更同步和编辑前后检查节点/边总量与重复边。

PowerShell：

```powershell
$env:CODEGRAPH_SKIP_TEST_BUILD = '1'
$env:CODEGRAPH_RELIABILITY_BENCHMARK = '1'
$env:CODEGRAPH_RELIABILITY_REPORT = Join-Path $PWD 'docs/person/index-reliability-measurements.json'
npm run test:focused -- __tests__/index-reliability-benchmark.test.ts --maxWorkers=1
```

新连接首次查询保留 Node 进程和操作系统文件缓存，不等于 CLI 冷进程启动或冷磁盘。样本采用唯一名称、有限扇出，不代表复杂 Go 工程；跨升级边数、真实大型工程 p50/p95、推断误报率与长时间多客户端负载需在固定真实代码快照上补测。

## 本次测量

Windows、Node v24.16.0，2026-10-01 20:19（UTC+8）开始；其他验证任务结束后单 worker 串行运行，耗时 234.5 秒。原始数据、基线提交和测量时的源码指纹见[测量数据](index-reliability-measurements.json)。源码行数含空行。

| Go 源文件 | 节点 | 边 | 重复边 | 编辑后主库 MiB | MiB/千文件 | MiB/万源码行 |
| --- | --- | --- | --- | --- | --- | --- |
| 100 | 400 | 600 | 0 | 0.75 | 7.50 | 6.82 |
| 1,000 | 4,000 | 6,000 | 0 | 5.39 | 5.39 | 4.90 |
| 5,000 | 20,000 | 30,000 | 0 | 25.35 | 5.07 | 4.61 |

五次无变更同步与五次正文编辑后，节点、边和词表条数保持稳定；编辑前后主库大小相同。5,000 文件库有 664 个空闲页（约 2.59 MiB），编辑后 WAL 为 638,632 字节。主库在首次几次同步中的增长伴随空闲页增加，不能据此认定有效数据持续膨胀。总磁盘使用须将 WAL 一并统计。

5,000 文件样本编辑后的查询耗时（毫秒）：

| 模式 | 新连接 p50 | 新连接 p95 | 热查询 p50 | 热查询 p95 |
| --- | --- | --- | --- | --- |
| explore | 140.5 | 149.9 | 19.9 | 27.4 |
| callers | 297.5 | 307.9 | 7.0 | 13.5 |
| impact | 287.5 | 294.6 | 4.4 | 9.3 |

编辑前后三种热查询 p50 均未上升，p95 有少量波动；这两批短采样不能证明长期趋势。无变更整库同步 p50/p95 分别为 11.24/19.81 秒，仍受全目录核验和 Windows 文件系统成本影响；watcher 使用按路径同步，不承担同样的整库扫描。

类型检查与相关测试通过，详细命令、跳过项、初始失败及产物限制见[开发验证记录](test-repairs.md#2026-10-01索引可靠性审查)。本轮没有完整验证新的安装产物、三平台或长期负载。
