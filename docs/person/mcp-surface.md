# MCP 表面与缓存稳定性

## 目标与取舍

默认 MCP 继续只暴露 `codegraph_explore` 和 `codegraph_edit`。本轮不拆分新工具，也不删除结构化查询、LSP、变更分析或事务编辑能力。优化重点是减少每个会话固定携带的说明和 schema，并让固定字节不随已索引项目规模变化，为宿主或模型供应商的前缀缓存创造条件。

缓存是否实际命中仍由宿主、模型和请求前缀策略决定。查询返回的源码和证据是动态内容，不能也不应为了缓存而省略。

## 实现

- 初始化说明只保留工具选择、源码完整性边界、编辑安全和未索引项目处理，不再重复 schema 教程。
- 两个默认工具及字段描述改为短契约；工具名、参数、枚举、默认值和执行行为不变。
- `getTools()` 不再把项目文件数和建议调用次数拼进 `codegraph_explore` 描述。默认 tools/list 不会随仓库规模或索引变化而改变；项目规模建议仍在具体 explore 结果中按需出现。
- explore 响应中重复的源码声明、完整性说明、调用建议和截断尾注改为短事实句，保留源码、证据、遗漏符号和继续查询入口。
- 无默认项目时，schema 仍把 `projectPath` 标为必填；显式 `CODEGRAPH_MCP_TOOLS` 白名单仍按用户配置改变表面。
- `codegraph_edit` 仍支持一次性 `apply:true`；只有预览后两步写入才需要回传 `expectPreviewHash` 并复用 `operationId`。预览仅在 `canApply:true` 且 `blockers` 为空时适合应用。

按当前构建产物直接序列化测量，不换算或声称模型 token 数：

| 固定表面 | 修改前 | 修改后 | 变化 |
| --- | ---: | ---: | ---: |
| MCP 初始化说明 | 11,386 | 2,251 | -80% |
| 默认 tools/list | 8,952 | 5,033 | -44% |
| 合计 | 20,338 | 7,284 | -64.2% |

`codegraph_explore` 仍有 19 个字段，`codegraph_edit` 仍有 11 个字段。字符预算测试固定初始化说明、无根说明、默认 tools/list、合计和单工具描述上限；工具注解测试同时固定已索引项目的 explore 描述与静态定义一致。

## 遥测

匿名使用统计默认关闭。未显式开启时不记录、不创建遥测文件、不联网；安装器默认不勾选。`codegraph telemetry on` 保存开启选择，`CODEGRAPH_TELEMETRY=1` 仅临时开启当前环境并保存稳定机器 ID，不会把全局状态永久改为开启。

安装器或 CLI 保存的选择继续生效。旧版本自动生成的 `consent_source: "default-notice"` 与环境临时生成的 `env` 记录都不视为显式同意，移除环境变量或升级后回到默认关闭。

## 发布状态
