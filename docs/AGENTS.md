# Documentation collaboration

- Documentation follows the current source and validation results; historical measurements, plans, and shipped capabilities are each labeled as such.
- Personal differences and processes go in `person/`; general technical explanations go in the matching topic document. Navigation pages do not repeat the body text.
- When changing a feature, update the entry point, contract, and test locations together; when moving a document, fix its references.
- For evaluation tasks read [Validation methodology](validation.md); do not write full worked examples back into AGENTS.md.
